## Repository 1

**Repository Name:**  xarray-spatial
**Link:**  https://github.com/xarray-contrib/xarray-spatial
### Purpose
What does this project do?
Provides instruction and algorithms for the python library xarray-spatial and its implementation. 

### Repository Structure
What folders or files stand out?
The main folders are benchmarks, docs, examples, img, and xrspatial. There are also quite a few files that are not organized within any of the folders. The benchmark folder also contains its own readme.md file that is separate from the repositories. 

### Documentation
How helpful is the README?
The readme for the repository contains a lot of useful information. However, its length could be overwhelming at first glance and difficult to navigate. 

### Activity
Is the repository actively maintained?
Yes, the last update was 9 days ago. 

### Key Observation
One thing this project does well.
It is very comprehensive in its instruction of algorithms. The folder and file names are also clearly labeled and relatively easy to follow within the organization structure.

## Repository 2
**Repository Name:**  spatial-analysis-R
**Link:**  https://github.com/jamiecmontgomery/spatial-analysis-R

### Purpose
What does this project do?
Provides a tutorial for working with raster data in R

### Repository Structure
What folders or files stand out?
The main instruction files for this project, Intro_spatial_data_R are not organized within a folder system. The creator opted to instead organize the data used in the tutorials into the folders. 

### Documentation
How helpful is the README?
The readme gives a decent overview of what the repository is. The most helpful section details the required packages for the data. 

### Activity
Is the repository actively maintained?
The repository is not actively maintained. 

### Key Observation
One thing this project does well.
The file structure is straightforward and easy to follow without much exploring of the repository. The filenames are also intuitive. 

## Repository 3
**Repository Name:**  gods-eye-view
**Link:**  https://github.com/bilawalsidhu/gods-eye-view

### Purpose
What does this project do?
Provides a 3D globe with live tracking data from public signals.

### Repository Structure
What folders or files stand out?
The repository has quite a few folders and subfolders within the hierarchy. One system that stuck out was the docs folder, which has a media subfolder, and an additional starthere subfolder.

### Documentation
How helpful is the README?
The readme is comprehensive and provides clear instructions are the start up process and unique tools within the application. The constant tags to Youtube videos does distract from the information being shared. 

### Activity
Is the repository actively maintained?
Yes, the repository is being actively maintained. 

### Key Observation
One thing this project does well.
The project has kept the mass amounts of data well organized within its folder system. Files do not appear to be misplaced.
